# نموذج واجهات نظام الموارد البشرية

هذا المستودع يحتوي على نموذج واجهات أولية لنظام إدارة الموارد البشرية والهيكل التنظيمي.

## المحتوى

- شاشة تسجيل الدخول
- لوحة الإدارة العليا
- لوحة الإدارة التنفيذية
- إدارة المناطق والمسؤوليات
- تعيين مسؤول وربطه بنطاق صلاحية
- بوابة المسؤول
- دليل الأفراد والبحث
- إضافة شخص
- بطاقة الشخص
- الاقتراحات والموافقات
- إضافة تقييم

افتح `index.html` أو `hr-platform-prototype.html` لمشاهدة النموذج.
