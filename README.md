# نموذج واجهات شؤون الدولة

هذا المستودع يحتوي على نموذج واجهات أولية لنظام شؤون الدولة والهيكل التنظيمي.

## المحتوى

- شاشة تسجيل الدخول
- بوابة دخول أولية قبل فتح النظام تطلب اسم المستخدم وكلمة المرور
- حساب المرحلة الأولى للجنة العليا: اسم المستخدم `supreme.admin` وكلمة المرور `1`
- هوية بصرية حكومية مميزة باسم "شؤون الدولة" مستوحاة من ألوان العلم العراقي
- شريط جانبي يمين، رأس صفحات رسمي، وبطاقات مؤشرات بهوية موحدة
- تحسين سهولة الاستخدام: قائمة جانبية مقسمة، إجراءات سريعة، وصفحة رئيسية مختصرة
- نموذج إضافة شخص بخطوات متتابعة: البيانات، التشكيل، المراجعة والحفظ
- صفحة مخطط تنظيمي مركزة تعمل كمساحة واحدة، مع عرض تفاصيل التشكيل داخل نفس الصفحة
- صلاحيات Role + Scope: اللجنة العليا ترى الكل، الإدارة التنفيذية ترى نطاقها، ومسؤول التشكيل يرى نطاقه فقط
- إخفاء الصفحات غير المسموحة من القائمة والبحث والإجراءات بدلاً من عرض صفحة "لا تملك صلاحية"
- لوحة اللجنة العليا
- أزرار استيراد وتصدير بيانات الأفراد من صفحة اللجنة العليا؛ الاستيراد يدعم صيغ Excel/CSV مثل `.xlsx` و`.xls` و`.xlsm` و`.csv`، ويتعامل مع ترميزات عربية مثل UTF-8 وWindows-1256، ويضيف أو يحدث الأفراد دون حذف البيانات السابقة، ويعرض بيانات البطاقة الأساسية بلغة عربية واضحة، ويربط الأفراد بالتشكيلات المناسبة عند تطابق الوظيفة أو الجهة التنظيمية
- لوحة الإدارة التنفيذية
- الصلاحيات والنطاقات ضمن اللجنة العليا
- تعيين مسؤول وربطه بنطاق صلاحية
- صفحة تعيين مسؤول تدعم اختيار كل المحافظات العراقية ضمن نوع المسؤولية "محافظة"
- بوابة المسؤول
- دليل الأفراد والبحث يعرض كل الأشخاص الموجودين في النظام بعد الإضافة اليدوية أو الاستيراد
- قاعدة بيانات محلية للأفراد تحفظ الإضافات والاستيرادات داخل المتصفح حتى بعد إغلاق وفتح النظام
- تفعيل تبويبات بطاقة الشخص: التقييمات، الملاحظات، وسجل النشاط مع حفظها داخل قاعدة الأفراد المحلية
- الاستيراد والتصدير حسب التشكيل: أزرار صفحة التشكيل تصدر أو تستورد أفراد هذا التشكيل وفروعه فقط، بينما أزرار الصفحة الرئيسية تعمل على كل النظام
- اعتماد `معرف الشخص` كمفتاح أساسي للتحديث ومنع تكرار السجلات عند إعادة الاستيراد
- دعم SQLite للمرحلة الأوفلاين عبر تشغيل `run-offline-sqlite.bat` من جذر المشروع؛ تحفظ القاعدة في `outputs/state_affairs_people.sqlite`
- إضافة شخص
- بطاقة الشخص
- الاقتراحات والموافقات
- إضافة تقييم
- المخطط التنظيمي التفاعلي لمكتب رئيس مجلس الوزراء مع نموذج عمل رسمي يربط اللجنة العليا، الإدارة التنفيذية، الجهات، المسؤولين، الأفراد، البيانات، التقييمات، والملاحظات
- عرض الهيكل العام للدولة داخل صفحة المخطط نفسها، مع إظهار تفاصيل أي قسم بالضغط عليه وإخفائها عند الضغط مرة أخرى
- مؤشرات خضراء للتشكيلات المشغولة وحمراء للشاغرة
- مركز إشعارات مع عداد غير المقروء وروابط مباشرة للطلبات والتشكيلات
- صفحة التقارير والتحليلات مع KPI ورسوم بيانية للتشكيلات والشواغر والتقييمات
- بحث ذكي فوري في الأشخاص، التشكيلات، الوزارات، المحافظات، والأقضية
- شريط مسار تنظيمي داخل المخطط مع أدوات تكبير وتصغير وفلترة
- نموذج إضافة شخص محسن بمؤشر اكتمال ومراجعة قبل الحفظ
- تفعيل أزرار النظام غير التنقلية: التصدير، الطباعة، فتح التقارير، الموافقات، الفلاتر، التبويبات، والهيئات
- بيانات الوزارات: 23 وزارة ضمن السلطة التنفيذية
- فرع تفاعلي لتشكيلات وزارة النقل العراقية مع 10 تشكيلات ومهام كل تشكيل

افتح `index.html` أو `hr-platform-prototype.html` لمشاهدة النموذج.

## نموذج البيانات الرسمي

- `org-data-model.md`: شرح كيانات النظام وقواعد الشواغر والربط.
- `org-units.seed.json`: بذرة أولى للهيكل التنظيمي الرسمي.
- `ministries.seed.json`: بذرة الوزارات ضمن السلطة التنفيذية.
- `ministry-transport.seed.json`: بذرة تشكيلات وزارة النقل العراقية.
- `org-schema.sql`: مخطط PostgreSQL مبدئي لبناء قاعدة البيانات والـAPI.
- `shuon-aldawla-people-template.xlsx`: نموذج Excel موحد لاستيراد وتصدير بيانات الأفراد.
